01这份 SOP 怎么用

这是用 Claude 一步步搭看板的指南（Windows 版），每个阶段告诉你：

  • 这一步要做什么（清楚目标）
  • 给 AI 的提示词长什么样（直接抄）
  • AI 会输出什么（你能预期）
  • 怎么验证它做对了（眼睛能看、手能点）
为什么是 Windows 版

整套做法跟 Mac 版一模一样，只是把几个工具换成 Windows 上对应的：定时用 Windows 自带的"任务计划程序"，命令行用 PowerShell。其他都一样，要用的软件 Windows 上也都能装。

03阶段 1：调研后台

🎯 目标：摸清后台有哪些报表、能取哪些指标

3.1 你要做的（人工部分）

  1. 登 admin 后台
  2. 把所有可能用得上的页面都点一遍，截图保存（Win+Shift+S 截屏）
  3. 记下每个报表能筛选什么 + 能导出多少行

3.2 让 AI 帮你梳理

⌘ 提示词
我把 admin 后台几个核心报表截图给你看。 你帮我整理出： 1. 每个报表的字段有哪些 2. 每个字段是"已经有"还是"要派生算" 3. 哪些字段对"商业化看板"最关键 4. 输出成一个表格：指标 / 后台位置 / 是否已有 / 取数说明 / 优先级（P0/P1/P2） 第一张截图：[截图]
验证：阶段 1 完成的标志
手里有一份"指标 → 后台位置"映射表，30-50 项 P0/P1 指标。

04阶段 2：设计指标体系

🎯 目标：决定看板分几个 tab，每个看什么
⌘ 提示词
基于刚才的指标表，帮我设计看板的 tab 结构。 要求： - 老板 30 秒能看懂的"总览大盘"放第一个 tab - 分维度（游戏 / 渠道 / 套餐...）每个一个 tab - 时间趋势单独一个 tab - 留存 / LTV 这种深度指标可以合并 输出每个 tab 的：标题 / 核心 KPI 卡 / 主要图表 / 表格列。
验证：阶段 2 完成的标志
能用 1 张纸画出 6-8 个 tab 的草图。

05阶段 3：写抓取脚本

🎯 目标：让程序自动登录后台、把报表数据抓下来、生成一个数据文件

5.1 先搞清楚你的后台是怎么登录的

后台登录常见有三种"关卡"组合，你先自己登一遍，看是哪种：

  1. 只有一个网页登录表单（填用户名密码就进）
  2. 先弹一个浏览器自带的小框（让你输用户名密码），过了之后才是网页登录表单
  3. 上面任意一种，再加一个每隔几十秒就变的 6 位验证码（谷歌验证器那种）

5.2 给 AI 提示词

⌘ 提示词
帮我写一个脚本，让它每次运行就自动做这几件事： 1. 登录我的后台（网址是 xxxx）。登录有三关：先弹一个系统的"输用户名密码"小框 → 再填网页上的登录表单 → 最后填一个每隔几十秒就变的 6 位验证码。 2. 按顺序打开这几个报表页面，把里面的数据抓下来：[报表 1 网址] [报表 2 网址] … 3. 把数据存成一个数据文件；每次只把新增的并进去，老数据保留、不要覆盖。 几点说明： - 这些报表是打开后才慢慢加载出来的，请用"能等它真正加载完再抓"的办法，别用只读网页源码的简单抓取。 - 那个会变的验证码，让脚本自己算，别让我每次手输。 - 账号密码不要写死在代码里，单独存一个文件让脚本读。 我电脑是 Windows，给我的操作和命令请按 Windows 来。账号密码我自己保管，不会贴给你。

5.3 AI 会做的几件事

  1. 问你每个报表的网址
  2. 把那个抓数据的脚本写出来
  3. 给你一个填账号密码的模板，让你把密码填进去
  4. 帮你把运行需要的环境和工具都装好（这步是 AI 敲命令完成的，你照着回车确认就行）
可能会遇到的一个小拦路

第一次在 Windows 上运行脚本，系统可能提示"无法加载脚本"——这是 Windows 默认不让随便跑脚本的保护。把下面这行复制到 PowerShell 里运行一次就放开了（对自己的脚本是安全的），然后按 Y 确认：

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
坑预警

第一次跑大概率失败 — 后台防抓取、超时、验证码对不上、抓错了位置……都正常。把报错原样发给 AI，让它来修，一般来回 2-3 次就能搞定。

验证：阶段 3 完成的标志
脚本跑完后，会生成一个新的数据文件 → 打开它，能看到熟悉的数字。

06阶段 4：看板前端

🎯 目标：把抓到的数据变成一个能点、能看的看板
⌘ 提示词
帮我把上一步抓到的数据做成一个看板网页。 要求： - 用现成的图表库画图（你来选合适的），别用复杂的前端框架；做成一个打开就能看的单页网页。 - 风格走"给老板看的高管范儿"：深海军蓝配暗金，干净利落。 - 数据直接用上一步生成的那个数据文件，别让我手动改。 页面按阶段 2 设计的 tab 来分：[tab 1] [tab 2] … 每个 tab 都要能： 1. 切时间区间（近 7 天 / 近 30 天 / 自己选起止） 2. 两个时期对比（本期 vs 上一期） 3. 表格点列头能排序 做完后告诉我在自己电脑上怎么打开预览（不用搭服务器）。
验证：阶段 4 完成的标志
在浏览器里打开你的看板 → 所有 tab 和数据都能正常显示。

07阶段 5：发布到 GitHub Pages

🎯 目标：让团队所有人能用浏览器看

7.1 让 AI 帮你建仓库 + 推

⌘ 提示词
帮我把当前这个文件夹发布成一个网页，让团队用浏览器就能打开看： 1. 在 GitHub 上建一个新项目（名字叫 commercial-dashboard，公开的就行） 2. 把我这个文件夹整个传上去 3. 打开 GitHub 自带的网页托管（GitHub Pages） 4. 弄好后，把看板的网址直接发给我 GitHub 我已经登录好了，你直接用命令帮我弄，别让我一步步手点。 另外帮我设置好"哪些文件不要传到 GitHub"——尤其是存账号密码的那个文件，千万别传上去；还有那些临时文件、运行日志，也都不用传。

上一步 AI 会直接把你看板的网址发给你。点开它，看板能正常显示就行。然后把这个网址转给同事，他们也能打开看。

08阶段 6：Windows 任务计划程序定时

🎯 目标：脚本每 30 分钟自动跑，数据持续更新

8.1 让 AI 帮你设置 Windows 自动定时

这一步其实是两件事：

  1. 做一个"一键启动"的小脚本：自动跑抓数据 + 把新数据上传，打包成一步
  2. 用 Windows 自带的"任务计划程序"，让它每 30 分钟自动触发这个小脚本
⌘ 提示词
帮我在 Windows 上把抓数据这件事设成"每 30 分钟自动跑一次"： 1. 先写一个小的启动脚本，让它每次自动完成：跑那个抓数据的脚本 → 把新数据上传上去（万一某次出错就跳过，别卡住）→ 把运行过程记到一个日志文件里。 2. 再用 Windows 自带的"任务计划程序"把它设成定时任务： - 每 30 分钟跑一次，开机后就开始 - 用我当前这个账号跑就行，不用管理员权限 - 就算笔记本没插电源也照样跑 3. 设好后帮我手动触发一次，看看日志里有没有正常输出，确认能跑通。 我电脑是 Windows，命令和操作都按 Windows 来。

8.2 让自动上传不用每次输密码

AI 会教你装一个"凭据管家"（Windows 版的 Git 一般自带），第一次上传之后登录信息就自动记住了，以后不用再输。

不想用命令？图形界面也行

不想敲命令的话，在开始菜单搜"任务计划程序" → 创建任务 → 用图形界面一步步点也能配好。AI 两种办法都会教。

验证：阶段 6 完成的标志
  • "任务计划程序"里能看到你那个定时任务
  • 手动触发跑一次，运行日志里出现"数据已更新"之类的成功提示
  • 过 30 分钟，去 GitHub 项目里看一眼，会自动多出一条"数据更新"的记录
  • 刷新看板页面 → 顶部的时间戳变成"刚刚更新"

09团队使用 / 边界明确

9.1 发给团队的话

团队使用说明（直接抄给同事）

看板地址：[贴上 AI 给你的看板网址]

  1. 每天打开看就行，不用登录
  2. 看 header 时间戳：🟢绿 = 数据新；🟡黄 = 4 小时+；🔴红 = 1 天+
  3. 看到红色 → 找你们自己的开发人员

9.2 Windows Lite 版的边界

⚠️ 这些情况下数据不会更新
  • 你 Windows PC 关机（睡眠状态有时也会停 — 看 Windows 电源设置）
  • 你 PC 不在公司网（出差不接 VPN）
  • 后台改了密码 / 重置了那个验证码

团队反馈"数据卡了"先检查这三条。

关于 PC 睡眠 / 待机

Windows 默认会在闲置一段时间后进入"现代待机 (Modern Standby)"，可能导致任务计划程序的定时不触发。处理：

  • 电源设置 → "屏幕和睡眠"，把"使用电池电源时电脑进入睡眠"和"接通电源时电脑进入睡眠"都设为 从不（屏幕可以关，但 PC 不睡）
  • 或者：任务计划程序的任务属性里勾"唤醒计算机以运行此任务"

9.3 团队点"刷新"按钮会怎样？

Lite 版的"刷新"按钮只是把页面重新加载一下，拿网上当前最新的那份数据。它不会让程序重新去后台抓一遍。

想要"点刷新就立刻去抓最新数据"，得升级到 Pro 版（加一台服务器）。

10关键经验

10.1 怎么和 AI 高效对话

  • 先讲背景再讲需求。"我在做 xxx 项目，遇到 yyy 问题" 比 "怎么 yyy" 好 10 倍
  • 报错原样发，不要意会
  • "你这步为啥这样做" — 不懂就问，AI 会解释
  • 不满意直说，AI 是工具不是同事

10.2 Windows 上几个常见小麻烦

下面这些是 Windows 上偶尔会冒出来的小问题，AI 基本都会自动处理好，你不用懂细节。万一遇到了，把现象告诉 AI 就行：

  • 文件路径的写法（Windows 的斜杠方向跟别的系统不一样）
  • 偶尔打印出乱码（中文编码问题，AI 加一句设置就好）
  • 公司 VPN / 防火墙可能拦住程序联网，启动慢或超时 → 找 IT 确认
  • 第一次安装时要下载一个比较大的程序（200MB+），杀毒软件有时会拦 → 临时关掉或把它加进白名单

10.3 必须人工把关的环节

  • 账号密码、那个会变的验证码的密钥，不要发到 AI 对话框里（让 AI 用"隐藏输入"的方式，让你自己输进去）
  • 每次上传之前，瞄一眼要传的内容，确认没把存密码的那个文件也一起传上去

10.4 卡住了怎么办

  1. 把全部上下文发给 AI：你做了什么、看到什么、期望是什么
  2. 如果 AI 也卡住，让它给你 3 个不同的尝试方向
  3. 真不行 → 发到 Stack Overflow / 群里求助
最后一句

非技术背景搭这个系统的最大风险，不是不会写代码，而是不清楚自己要什么。把指标体系想清楚（阶段 1+2），后面 AI 会带着你走。
