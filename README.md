# g654321 商业化指标看板

📊 **互动 BI 看板** · 数据快照 2026-05-28

## 怎么用

### 方式 1：本地双击运行（最简单）

```bash
# 克隆下来
git clone https://github.com/eightnrcn2025-create/commercial-dashboard-2026-05.git
cd commercial-dashboard-2026-05

# 本地开服（任选一种）
python3 -m http.server 8765
# 然后浏览器打开 http://localhost:8765
```

或直接双击 `index.html` 也能打开（但有些浏览器禁止 file:// 加载本地 JS，所以推荐用 http server）。

### 方式 2：发给经理

仓库是 **PRIVATE**。要分享：
- **Settings → Collaborators → 邀请经理的 GitHub 账号**（他能 clone 后本地打开）
- 或者你打开看板，**截图发飞书/钉钉**

## 文件清单

| 文件 | 内容 |
|---|---|
| `index.html` + `data.js` + `app.js` | 互动看板（ECharts）|
| `商业化看板-2026-05-28.xlsx` | 离线 Excel 版本 |

| `商业化看板-技术待办.md` | 给技术的需求清单 |

## 看板 7 个 Tab

| Tab | 内容 |
|---|---|
| **总览** | 8 个 KPI 大数字 + 昨日/7天/30天 对比柱图 + 新vs留存付费饼图 + 订单成功率曲线 |
| **30 天趋势** | 6 条指标可切换的折线图（带时间轴缩放）+ 完整日明细表 |
| **网游** | 23 款网游 KPI + 充值排行条形图 + 含 ARPU/ARPPU 派生列的表 |
| **单机** | 176 款单机概要 + TOP 20 消费 G 点排行 + 明细表 |
| **套餐** | 套餐收入条形图 + 支付成功率对比 + 完整漏斗表 |
| **渠道** | 渠道充值排行 + ARPU/ARPPU 表（看哪些小渠道值得加码）|
| **LTV / 留存** | 平台 D1/D7/D14/D30 LTV 曲线 + D1/D3/D7/D14/D30 留存率曲线 |

## ⚠️ 当前数据的局限

1. **「日活统计」页有 bug**，平台口径 DAU/留存取不到（仅网游留存能聚合出来）
2. **「通道日结算」页无权限**（要管理员开），但支付通道已能从订单管理派生
3. **平台 LTV/留存** 只含网游用户，单机用户行为不在内

详细技术待办见 [商业化看板-技术待办.md](./商业化看板-技术待办.md)
