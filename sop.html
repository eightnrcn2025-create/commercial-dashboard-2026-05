用 AI 搭一个商业看板

CLAUDE-DRIVEN BUILD PLAYBOOK · 选你的版本

这份 SOP 不教你写代码 — 教你用 Claude（或类似 AI）一步步搭出一个像 这个看板 一样的东西。

核心思路：你 不需要懂技术，需要的是 清楚自己要什么 + 会把它讲给 AI。AI 会写代码、AI 会处理细节、AI 会带你避坑。

读完任何一版的 SOP，你会知道：每个阶段问 AI 什么、AI 会回什么、怎么判断 AI 做对了。

先选系统（自己电脑）
Lite 版 macOS

Mac 跑就够

看板自动更新和数据抓取都在你 Mac 上。团队浏览器打开就能看。

  • ✅ 不花钱
  • ✅ 设置简单（一台 Mac + 几条命令）
  • ⚠️ Mac 必须开着（合盖睡眠 OK）
  • ⚠️ 出差不带电脑 = 没更新
看 Mac 版指南 →
Lite 版 Windows

Windows 跑就够

看板自动更新和数据抓取都在你 Windows PC 上。用 Task Scheduler 调度。

  • ✅ 不花钱
  • ✅ 设置简单（PowerShell + Task Scheduler）
  • ⚠️ PC 必须开着（睡眠 OK 但休眠会停）
  • ⚠️ 跟 Mac 版限制一样
看 Windows 版指南 →
想要全天候 / 团队随时刷新
Pro 版 Mac / Win 都行

常驻 VPS

看板的"自动更新"和"团队远程触发刷新"跑在一台云上小服务器（VPS）上，你电脑关机/出差都不影响。多一层架构，更省心。

  • ✅ 你电脑关机也照样更新
  • ✅ 团队点刷新立刻拉新数据
  • ✅ Mac / Windows 都可以（前 6 个阶段用对应 Lite 版，加阶段 7-8 即可）
  • ⚠️ 一台便宜 VPS（5-10 美元/月）
  • ⚠️ 多 2 个组件要设置
